# 降级与故障处理

## 没有 Python

先说明完整脚本模式需要 Python 3.9+，不擅自安装依赖。用户希望先体验时，可进入**手动简化模式**：

仅用宿主已有文件工具，在用户指定的安全工作区创建一个不冲突的 `手动体验-日期.md`，记录三段：用户明确提供的背景、资料来源及读取状态、本次草稿与待核对项。后续修改追加新版本；不覆盖旧内容。存长期要求前同样需要用户确认，另记适用范围及撤销标记。

手动模式没有脚本的去重、锁、校验、规则路由及数值计算保障。不能直接修改 `.chao/state.json` 冒充完整模式，不能自动把手动记录迁入正式档案，也不能宣称自动化测试或跨对话加载已通过。依赖齐全后，由用户确认具体记录再导入。

## WorkBuddy 没发现技能

检查是否为**桌面本地工作区**，目录是否是 `.codebuddy/skills/chao-knowledge/SKILL.md`；不要多套一层同名目录。新建对话并明确要求调用 `chao-knowledge`。需要时在技能面板确认启用状态；不同客户端版本界面可能变化，以官方文档和实际界面为准。

仍未加载时可明确让宿主读取该 SKILL.md 后按说明执行，必须报告这次是显式读取，不当成自动发现已通过。不要修改全局安全配置、关闭沙箱或启用不可信 hooks。

## 已有文件/规则冲突

安装器与初始化器拒绝覆盖不同版本技能、同名业务目录、异常状态或不安全路径。不要直接删掉已有文件重跑。给用户说明具体冲突和可选位置；成熟知识库先保留原结构，确认后在新的工作区试用，不自动迁移整库。

已有 AGENTS.md 与 .gitignore 在初次初始化时保留原文并追加明确标记，原文备份在 `.chao/backups/`。初始化后用户再修改这些文件，不会被重复 init 覆盖。追加规则仍受宿主更高优先级规则与权限约束。

## 链接、视频、Office 读不了

返回具体状态：只有链接、原件已保存但待提取、提取不完整或转写未核对。优先请求用户直接粘贴正文/逐字稿。额外工具、账号、付费 API 或联网步骤需要提前解释并获得授权，本包不自带这些能力。

## 数据损坏或遗失

停写并保留现状；用 health 定位缺失/变化。不要假装自动备份了所有历史：本包只为首次追加的配置保留原文，业务资料应由用户自行备份。`state.json` 损坏需要用户自己的可信备份；没有备份时按原始材料重新登记，不能伪造原 ID、确认或验收历史。

## 隐私提示

脚本只读写本地；宿主模型可能是云端服务。扩展名及密钥模式检查只是一层防误操作，不是全面 DLP、病毒扫描或内容安全认证。不要让秘密进入公开仓库；报告问题前脱敏。未经授权的内容不要导入、分享或用于商业发布。
