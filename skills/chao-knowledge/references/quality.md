# 成品验收与质量检查

## Agent 保存前检查

- 是否实际读取了这次引用的资料，而不是只保存了链接；
- 第一人称经历、客户、成绩、收入是否来自用户本人明确提供的依据；
- 团队、同事和外部作者案例是否保留正确归属；
- 时效信息是否已经核验或明确标记未核验；
- 适用规则是否与当前 task/platform/audience/project 匹配；
- 草稿是否保存为新版本，没有覆盖旧稿；
- 是否把需要用户确认的点单独列出来。

## 用户验收卡

向用户展示时保持简短：

1. 这次用了哪些档案/资料；
2. 哪些地方是推断或待核对；
3. 文件保存在哪里。

## 跨会话验收

新对话选择同一工作区，真实运行 `context`。核对返回的规则 ID、范围和档案字段，再让模型完成一个新任务。在同一聊天继续改稿不算跨会话验证。

## 自媒体额外检查

- 对标结构可以借鉴，不能逐句同义替换；
- 单条高播放或高收藏不能直接写成“已验证规律”；
- 发布数据的统计窗口和口径要一致；
- 复盘要区分事实、可能原因和下一次实验。
