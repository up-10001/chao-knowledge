# 知识库结构

Chao Knowledge v0.2 使用“可读层 + 机器层”两层结构。

## 可读层

用户可以直接打开这些文件和目录查看知识库当前状态：

- `开始这里.md`：最短使用入口；
- `本周重点.md`：当前阶段最重要的目标；
- `知识库地图.md`：数量、分类和导航；
- `01-我的档案/`：身份、业务、受众、经历和表达风格；
- `02-资料库/`：按用途分为对标、用户反馈、行业资料和素材；
- `03-内容中心/`：从选题到发布复盘的内容流；
- `05-经验与规则/`：长期要求、纠正记录、已验证经验和健康报告。

其中档案、地图、本周重点、长期要求和纠正记录由脚本从状态同步生成，文件顶部有 generated 标记，不建议手改。

## 机器层

`.chao/state.json` 保存资料记录、哈希、来源、规则作用域、作品版本和反馈快照，是机器事实源。`.chao/latest-health.json` 只在用户要求保存健康检查时生成。

## 为什么两层同时存在

只有 JSON 时，普通用户很难知道 AI 到底记住了什么；只有 Markdown 时，又容易出现多个文件互相矛盾。v0.2 用状态文件负责确定性，用可读 Markdown 负责透明度和日常使用。

## 更新与兼容

v0.1.x 工作区重新运行 `init` 时会补齐 v0.2 可见结构，但不会自动搬移旧目录。健康检查会把旧目录标记为 P2，迁移必须由用户确认后再处理。
