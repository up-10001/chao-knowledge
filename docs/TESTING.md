# 测试与验收边界

## 自动化测试

运行 `python3 -m unittest discover -s tests -v`。覆盖初始化与文件保护、可读视图同步、资料来源和去重、文本读取状态、规则作用域与撤销、作品版本、反馈数据、健康检查、安装完整性和路径安全。

自动化测试只验证确定性脚本行为，不验证真实模型是否会完全按 Skill 指令执行。

## WorkBuddy 客户端人工验收

发布前应至少验证：

1. 工作区能加载 Skill；
2. 初始化后能看到 v0.2 可见目录；
3. 保存档案后可读 Markdown 同步更新；
4. 导入对标资料后能区分外部作者和用户经历；
5. 新对话在同一工作区能重新加载已确认规则；
6. health 与 health --save 行为符合说明。

如果没有完成真实 GUI 验收，应在 VALIDATION.md 中明确标为 NOT_RUN，不得用单元测试代替。
