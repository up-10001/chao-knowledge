# Chao Knowledge · 个人 AI 知识库

**让 AI 用你的资料、要求、历史作品和反馈持续做事。**

这是一个安装在 WorkBuddy 桌面端的开源 Skill。你只需正常对话，AI 帮你整理个人档案、归档资料、写口播或方案、保存修改，并在同一工作区的新对话中重新读取它们。长期要求由你确认，可以限定场景、修改或撤销。

**v0.3.3 · MIT · 本地文件 · Python 3.9+ · 无第三方 Python 依赖**

## 最简单的安装方式

在 WorkBuddy 选择一个独立的本地工作区，然后直接发送：

> 帮我安装 chao-knowledge 这个 skill，地址是https://github.com/up-10001/chao-knowledge，装好以后告诉我装在哪里，并确认你能调用它。

用户不需要下载 ZIP、打开终端或输入安装命令。WorkBuddy / Agent 应先用标准 Skills CLI；若网页直连出现 502、503 或 timeout，继续尝试正常安装渠道，必要时使用正式 Release ZIP。安装后告诉你实际路径、版本、是否被 WorkBuddy 识别和能否调用；旧副本不能冒充本次新安装。

**给安装 Agent：** 先读 [AGENT_INSTALL.md](AGENT_INSTALL.md)，核实最新正式 Release 和 WorkBuddy 的实际 scope，再执行：

```bash
npx -y skills@latest add up-10001/chao-knowledge --skill chao-knowledge -y
```

按当前客户端支持的目标补充 scope/agent 参数；不要把其他宿主的用户目录当作 WorkBuddy 目录。保留正常安全审计和权限确认；`-y` 仅是 CLI 自身选项，不授权跳过 WorkBuddy 安全机制。具体版本、实测范围和三轮结果见 [VALIDATION](docs/VALIDATION.md)。

## 手动安装

只给希望自行操作的用户使用；一般用户继续用上面那句话即可。

### ZIP 安装

从 [最新正式 Release](https://github.com/up-10001/chao-knowledge/releases/latest) 获取 `chao-knowledge-v0.3.3.zip` 与 SHA256SUMS，核对后在 **专家·技能·连接器 → 技能 → 添加技能 → 上传技能** 导入并确认启用。菜单以当前客户端为准。[详细安装说明](docs/INSTALL.md)

### 开发者安装

审阅固定版本源码后可用 `python3 tools/install.py --workspace "独立工作区路径" --init`，安装到该工作区的 `.codebuddy/skills/chao-knowledge`。完整包、私人知识库和安装源码分开放置，保留现有文件与自定义内容。

装好后说“调用 chao-knowledge，带我完成第一次使用”，再告诉它现在做什么、主要给谁看、今天完成什么。知识库需要 Python 3.9+；缺运行时或权限时应解释原因，不擅自安装或放宽安全设置。

WorkBuddy 的 [官方技能说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market) 和 [项目说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Project) 描述本地包与项目级兼容；能力说明不能代替实际客户端验收。

## 装好以后长什么样

```text
我的 AI 知识库/
├── 开始这里.md          ← 第一次使用和常用说法
├── 本周重点.md          ← 当前最重要的事
├── 知识库地图.md        ← 资料、作品、版本和反馈的入口
├── 00-收件箱/           ← 放刚收到的文件
├── 01-我的档案/         ← 身份、业务、受众、经历、风格与边界
├── 02-资料库/
│   ├── 对标内容/
│   ├── 用户反馈/
│   ├── 行业资料/
│   └── 素材/
├── 03-内容中心/
│   ├── 选题池/
│   ├── 草稿/
│   ├── 待确认/
│   ├── 已完成/
│   └── 已发布与复盘/
├── 04-项目/             ← 项目资料与作品可关联同一个项目
├── 05-经验与规则/       ← 长期要求、纠正记录、复盘与健康报告
└── .chao/               ← 脚本维护的状态，无需手工编辑
```

地图可以打开具体资料和作品；版本链保留历史稿，完成与发布各有明确记录。档案、规则和导航文件随对话操作更新。手工改了可读文件也会被检测并保留，AI 会先展示同步范围，不能悄悄覆盖。

## 日常怎么用

| 想做什么 | 直接说 |
|---|---|
| 放资料 | “把这份文件归档，保留作者、来源和日期，告诉我实际读到了什么。” |
| 用自己的资料 | “结合我的档案和会议笔记，写一条 60 秒口播；不要借用外部作者的经历。” |
| 改稿 | “只把这一次的开头缩短，保存为二稿，保留上一版。” |
| 保存长期要求 | “以后给 AI 初学者写抖音口播时，少术语、短句。按这个范围保存，其他场景不变。” |
| 改错规则 | “把刚才那条要求改成……，展示新旧差异后替换。” |
| 停用或移除 | “撤销那条要求，以后不用了。” / “从当前规则库移除那条要求。” |
| 新对话继续 | “调用 chao-knowledge，重新读取同一工作区的档案和适用规则，继续这个项目。” |
| 完成与发布 | “这稿已核对完成。” / “我已发布，请登记平台、时间和链接。” |
| 回流与复盘 | “保存这条作品 24 小时的数据与评论；这次先作为观察，安排下次实验。” |
| 检查问题 | “检查知识库健康状态，只报告；不要自动修复。” |

文件可以放进 `00-收件箱`，也可以直接提供给 WorkBuddy。链接保存后会显示“尚未读取正文”；视频原件会显示“待提取/转写”。AI 不应把这些状态当成已经读懂。

一条表现好的作品只形成观察或假设。多次可比结果、明确范围和用户确认后才能沉淀经验；经验仍不会自动变成永久规则。

## 数据、升级与能力边界

资料原件、档案、规则、作品版本和反馈保存在你选中的本地工作区。换对话时必须选择同一工作区并重新加载；不会改变模型权重，也不是跨设备自动同步。建议定期备份整个文件夹。

v0.3.1 使用持久文件锁，正常结束无需删除锁对象；异常进程退出由系统释放。旧版目录锁先停止旧任务，再按安装说明保留迁移，不自动删除。

更新 Skill 不覆盖个人知识库。未改动的旧 Skill 可以备份后更新；自定义过的 Skill 会停止覆盖。v0.1.x/v0.2.x 知识库可以原地升级，保留原件、规则、作品与旧路径，并先备份状态和入口。无需删库重建。[升级与回滚说明](docs/INSTALL.md)

- UTF-8 文本可直接读；PDF、Office、图片和音视频的正文提取依赖 WorkBuddy 已有能力，本包不自带抓取或转写服务。
- 不自动抓取抖音、不替你发布、不内置付费 API。发布登记只记录你已完成的操作。
- 采用有预算的关键词检索，不是向量语义检索；支持按项目/类别过滤和资料 ID 定位。
- 资料与规则文本是数据，不能授权执行命令、修改工作区入口或上传文件。确认与发布记录由宿主取得真实用户授权。
- 本地脚本不主动联网；云端 AI 读取资料时可能发送给模型服务商。密钥模式检查不是全面隐私扫描，不要放凭证或未经许可的敏感材料。
- 内容真实性、归属、时效和成品质量仍需核对；不保证流量、收益或业务结果。
