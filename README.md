# Chao Knowledge · 个人 AI 知识库

**让 AI 用你的资料持续做事，而不是每次都从零认识你。**

Chao Knowledge 是一个面向 WorkBuddy 本地工作区的个人知识库 Skill。它把个人档案、资料、内容流程、长期要求和复盘放在同一个可见工作区里；底层状态由脚本维护，上层 Markdown 文件可以直接打开查看。

**v0.2.1 · MIT 开源 · Python 3.9+ · 无第三方 Python 依赖**

[快速安装](#快速安装) · [使用指南](docs/USAGE.md) · [知识库结构](docs/ARCHITECTURE.md) · [下载安装包](https://github.com/up-10001/chao-knowledge/releases/latest)

## 可以直接这样用

| 你想做的事 | 可以直接说 |
|---|---|
| 第一次搭建 | “调用 chao-knowledge，带我完成第一次使用。” |
| 存一份对标 | “把这份逐字稿放进对标内容，保留来源和作者归属。” |
| 写一条口播 | “结合我的档案和这份对标，写一条 60 秒口播，不要把对方经历写成我的。” |
| 保存长期要求 | “以后抖音入门口播句子短一点、少用术语；其他任务不变。” |
| 换对话继续 | “读取同一工作区的档案和已确认规则，再继续这个任务。” |
| 做发布复盘 | “把 24 小时后台数据关联到这条作品，区分事实、推测和下次实验。” |
| 检查知识库 | “检查知识库健康状态，给我 P0/P1/P2 问题，不要自动删除文件。” |

## 为什么不是普通文件夹

Chao Knowledge 同时维护两层：

- **人类可读层**：档案、地图、本周重点、资料分类、内容流程和规则文件；你可以直接打开检查。
- **机器事实层**：`.chao/state.json` 记录资料哈希、来源、规则作用域、作品版本和反馈快照，避免 AI 只靠聊天上下文猜测。

长期要求不是一句“记住了”就结束。规则需要明确作用范围，可以确认、替换、到期、撤销或移除；新对话只有在同一工作区重新读取后才算真正复用。

## 自媒体工作流

这版内置了适合内容创作的可见流程：

```text
账号/个人档案
      ↓
对标内容 / 用户反馈 / 行业资料 / 素材
      ↓
选题池 → 草稿 → 待确认 → 已完成 → 已发布与复盘
      ↓
把确认过的要求和多次验证的经验留下来
```

对标资料属于外部来源。Skill 会要求保留来源与归属，外部作者的经历、客户、收入或案例不能自动写成你的第一人称事实。

## 知识库健康检查

`health` 会检查：

- 必要目录和 WorkBuddy 入口是否存在；
- 资料、正文和作品文件是否缺失或被外部修改；
- 待提取资料、只保存链接的资料；
- 过期规则、待确认规则；
- 个人档案、本周目标是否缺失；
- 收件箱是否长期积压；
- 是否仍存在 v0.1.x 旧目录。

结果按 **P0 / P1 / P2** 分级。默认只检查；明确要求保存时才生成 `latest-health.json` 与可读健康报告，不会自动移动、覆盖或删除资料。

## 快速安装

先在电脑上新建一个独立文件夹，例如 **“我的 AI 知识库”**，在 WorkBuddy 桌面端选中它作为工作区，然后发送：

```text
请从这个公开仓库安装 chao-knowledge 的 v0.2.1：
https://github.com/up-10001/chao-knowledge

先读取 README 和安装说明，检查 Python 3.9+ 与必要文件权限。
按 tools/install.py 把 skills/chao-knowledge 安装到当前工作区的 .codebuddy/skills/chao-knowledge，并初始化知识库。
保留已有文件；遇到目录或配置冲突先停止，不要直接覆盖。
安装完成后调用 chao-knowledge，带我完成第一次使用：只补齐必要的个人背景、受众和当前目标，然后让我提供一份真实资料，完成一个真实任务。
外部作者的经历、成绩、客户和观点必须保留归属，不能自动写成我的经历。
遇到读取、依赖或权限问题请明确说明，不要假装成功。
```

手动安装、ZIP 导入和更新方式见 [INSTALL](docs/INSTALL.md)。

## 使用边界

- TXT、MD、CSV、JSON、SRT、VTT 可直接读取 UTF-8 文本；PDF、Office、图片、音视频先保存原件，正文读取/转写依赖宿主已有能力。
- 保存视频链接不等于下载或转写视频；本包不内置视频抓取器、自动发布器或付费 API。
- 本地脚本不主动联网，但云端 AI 读取本地资料时可能把内容发送给模型服务商；不要保存密钥或未经授权的敏感资料。
- 关键词检索不是向量语义检索，也不是事实核验。
- 作品仍需人工验收；本项目不保证播放量、收益或业务结果。
