# Chao Knowledge · 个人 AI 知识库

**让 AI 用你的资料做事，而不是每次都重新认识你。**

在 WorkBuddy 中整理资料、调用个人背景、完成内容创作，并保存你确认过的要求。资料和作品放在自己的工作区，下次需要时继续使用。

**v0.1.1 · MIT 开源 · Python 3.9+ · 无第三方 Python 依赖**

[立即安装](#快速安装) · [使用指南](docs/USAGE.md) · [下载安装包](https://github.com/up-10001/chao-knowledge/releases/latest) · [常见问题](docs/INSTALL.md#常见问题)

## 可以用它做什么

| 使用场景 | 可以直接这样说 |
|---|---|
| 建立个人知识库 | “帮我建立知识库，带我完成第一次使用。” |
| 整理资料 | “把这份资料存进知识库，告诉我读到了什么。” |
| 写口播、方案或总结 | “结合我的背景和这份资料，帮我写一份初稿。” |
| 保存写作要求 | “以后写口播时，句子短一些、少用术语；其他场景不变。” |
| 在新对话中继续使用 | “调用 chao-knowledge，按我保存的要求继续。” |
| 整理作品反馈 | “把这份发布数据关联到作品，帮我复盘。” |

归档会保留原件、来源和读取状态；草稿会保留版本和依据。长期要求在你确认后保存，也可以查看、修改和撤销。

## 快速安装

在电脑上新建一个独立文件夹，例如 **“我的 AI 知识库”**，并在 WorkBuddy 桌面端选中它作为工作区。然后复制下面这段话发送：

```text
请从这个公开仓库安装 chao-knowledge 的 v0.1.1 版本：
https://github.com/up-10001/chao-knowledge

先读取 README 和安装说明，检查 Python 3.9+ 及必要的文件权限。
按 tools/install.py 的方式，把 skills/chao-knowledge 安装到当前工作区的 .codebuddy/skills/chao-knowledge，并初始化知识库。
保留已有文件，遇到冲突不要覆盖；不要关闭安全设置或额外开通付费服务。
下载和解压放在临时目录，不要把源码仓库当作我的私人知识库。
安装完成后，调用 chao-knowledge，带我完成第一个任务。
已有信息不要重复问，只补充必要的个人背景、目标受众和本次任务，再引导我提供一份资料。
资料、示例和外部作者的经历不要写成我的经历。遇到依赖、权限或读取问题，请如实说明。
```

安装完成后，在同一工作区新建对话，说：

> 调用 chao-knowledge，带我完成第一次使用。

手动安装、ZIP 导入与更新方法见 [安装说明](docs/INSTALL.md)。

## 开始使用

### 放入资料

把文档、笔记或逐字稿提供给 WorkBuddy，说：“放进我的知识库。”它会保留原件并记录来源，说明哪些正文已经读取、哪些还需要提取。

### 用自己的资料完成作品

告诉它这次要做什么，例如：“结合我的介绍和刚才的资料，写一条 60 秒口播。”它会按本次任务调用相关资料与已确认的要求，保存草稿，并列出来源和待核对项。

### 保存适合长期使用的要求

例如：“以后写口播时少用术语，其他任务不变。”确认内容与适用范围后保存。在同一工作区的新对话里，可重新调用这些要求；不再需要时直接要求撤销。

### 把结果留下来

完成作品后，可以继续保存修改版本、整理发布数据和复盘笔记。缺失的数据会保留为空，不会用猜测补齐。

更多可直接使用的指令见 [使用指南](docs/USAGE.md)。

## 资料保存在哪里

```text
我的 AI 知识库/
├── AGENTS.md                 # 工作区入口
├── 开始使用.md               # 常用指令
├── 00-待整理/                # 待归档资料与临时稿
├── 01-资料/                  # 原件、可读文本与来源
├── 02-作品/                  # 草稿、版本与来源卡
├── 03-复盘/                  # 反馈记录与数据快照
├── .chao/state.json          # 档案、规则与资料登记
└── .codebuddy/skills/chao-knowledge/
```

无需手动维护这些文件，直接用自然语言提出任务即可。请将私人知识库与公开源码分开保存，不要把个人或客户资料一起上传到 GitHub。

## 使用前了解

- **运行环境：** 面向 WorkBuddy 桌面本地工作区，完整脚本功能需要 Python 3.9+。客户端中的技能加载和执行结果取决于实际版本与权限；当前尚未完成 WorkBuddy GUI 实测，详见 [验证记录](docs/VALIDATION.md)。
- **支持的资料：** TXT、MD、CSV、JSON、SRT、VTT 可读取 UTF-8 文本；其他文档、图片和音视频先保存原件，正文提取依赖 WorkBuddy 已有能力。单文件上限 32 MiB，自动读取文本上限 2 MiB。
- **链接与记忆：** 保存视频链接不等于下载或转写视频；跨对话复用需要选择同一工作区并实际加载知识库，不是训练模型或永久记忆。
- **费用与隐私：** 本包不内置付费 API，WorkBuddy 与模型费用以对应服务为准。脚本不主动联网，但云端 AI 读取资料时可能发送给模型服务商；不要存入口令、密钥或未经授权的敏感资料。

生成内容仍需自行核对。本项目不提供自动发布，也不保证内容表现或收益。
